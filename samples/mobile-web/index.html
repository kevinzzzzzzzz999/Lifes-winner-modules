安装只需三步 Three steps to install

  1. 用 Safari 打开上面某个工具。
    Open one tool in Safari.
  2. 点分享 →「添加到主屏幕」→「添加」。如有「作为网页 App 打开」，保持开启。
    Tap Share → Add to Home Screen → Add. Leave Open as Web App enabled if shown.
  3. 从主屏幕点图标，联网等到「可离线使用」。三个工具分别安装。
    Open its Home Screen icon while online and wait for Ready for offline use. Install each tool separately.
