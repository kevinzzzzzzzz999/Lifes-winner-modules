工具列表

内容只在你的设备处理

三个工具没有账号、广告、分析统计、追踪器或云端处理接口。画板、偏好和文档内容在浏览器内处理；本地草稿只写入当前设备的网站存储。没有访问完整版 Life's winner 数据、通讯录、相册或设备身份的代码。

打开工具时，托管服务会收到常规网页和静态文件请求，例如 IP 地址等连接信息，适用托管方的隐私政策。应用不会将编辑内容、文件名或草稿加入请求、网址或诊断日志。

导出、分享与备份

只有你主动点击导出或分享，才会交给系统下载／分享面板。你自行选择保存位置或收件应用。请为重要内容定期导出；网站数据可被清除或回收，本地草稿不是长期备份。卸载重装、安装前后的 Safari、不同浏览器与设备可能使用不同存储空间。

三个工具分别安装

各自具有独立的图标、启动页、安装范围、草稿名称和离线缓存，只缓存所选工具及公共界面文件。同一托管来源内的网页不等于三个操作系统安全沙盒；这里采用独立存储键和代码边界，不提供跨工具共享内容。偏好方案编辑器不会修改系统设置或完整版应用；文档工具编辑的是你选择文件的本地副本；画板使用独立文件格式。

离线和更新

首次需要联网，显示「可离线使用」后可在断网时打开。每月检查并发布已完成的更新；有更新时先保存或导出，关闭当前工具的全部窗口，再重新打开。服务端不会删除本机草稿或自动导入外部内容。浏览器功能支持可能因系统版本而异。

许可与源码

源码按 MIT 许可开放。公开发布只包含经过检查的功能代码、合成示例和原创图标，不包括原作者的笔记、账号、设备标识、个人签名材料或本机配置。

Privacy and scope

The three tools have no accounts, advertisements, analytics, trackers or content upload service. Documents and drafts are processed in your browser and stored only on your current device. They do not scan the full application's notes, contacts, photo library or device identity.

The static hosting provider receives ordinary page requests and connection information, such as your IP address, under its own privacy policy. This application does not add edited content, filenames or drafts to requests, URLs or diagnostic logs.

Export and backup

Files leave the app only when you explicitly choose export or system sharing. You choose the destination. Export important work regularly: clearing website data, uninstalling or system storage cleanup may erase drafts. Safari, installed apps, browsers and devices may have different storage.

Independent tools

Each app has its own launch identity, scope, draft keys and offline cache. Installing one downloads only that tool and shared interface files. Logical separation on the same web origin is not an operating-system security sandbox. Preferences affect this tool and exported plans, not system settings or the full application. Documents edits a copy of the selected text file. Writing has its own JSON format.

Offline use and updates

Open online first and wait for Ready for offline use. Completed code updates are reviewed and published monthly. A new offline version waits until all windows of that tool are closed; save or export before closing. Personal content is not synchronized across devices or uploaded by the update process.

License and publication

Source code is available under the MIT license. Published files contain reviewed code, synthetic examples and original icons, without the creator's private notes, accounts, device identifiers, signing credentials or local configuration.
