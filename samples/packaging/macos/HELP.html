life'winner Tools · 使用帮助

希望每一个使用我开源功能的人，都是各自的 life'winner。

两个可独立使用的 Mac 小工具。不需要 Xcode、Node、账号或联网。

书写画板 · life'winner Writing

用鼠标或触控板画线。选择 Hold line / Hold shape 后，画出对应轮廓并停住约 0.65 秒，绿色预览出现后松开。Wave 是波浪线，Fill 在松开后闭合填色，Laser 松开后消失。

Tape 用于遮挡；Reveal tape 可逐条揭开，Toggle tapes 可整体揭开。文字输入框生成文字卡。Undo / ⌘Z 撤销；Clear 清空画板。

保存：点 Export JSON 选择保存位置，Open JSON 重新打开。退出前请手动导出。激光、草稿和撤销历史不会导出。它使用自己的绘图文件，不读取原 life'winner 笔记，也不是完整笔记软件。

Mac 版不识别手写文字。iPad Apple Pencil / 系统随手写适配在开源组件中另行提供。

偏好方案编辑器 · life'winner Preferences

编辑语言、布局、笔栏、手势意向与播放外观等独立方案，适合试用和分享组件的设置数据。不会改变 Mac 系统或原 life'winner 的设置，也不会执行 AI、翻译、音视频播放或 Apple Pencil 操作。

保存：修改后点 Save / 保存。方案保存在当前用户的 ~/Library/Application Support/InkSpace Preferences/settings.json；重新打开应用会恢复。Reset defaults 只恢复当前预览，点保存后才保留。Reload 会重新读取上次保存。

Import / 导入方案读取本工具的版本化 JSON；导入后点保存可长期保留。Export / 导出方案把当前方案保存到你选择的位置，便于分享。错误、过大或其他应用格式的文件会被拒绝，当前方案仍保留。

首次打开与隐私

将 .app 拖入“应用程序”或你选择的文件夹后打开。应用使用本地 ad-hoc 签名，没有 Apple 开发者证书或公证；从互联网下载后 macOS 可能阻止首次打开。请自行阅读系统提示，按照 Apple 官方说明在“系统设置 → 隐私与安全性”审查是否允许。不要关闭 Gatekeeper，不需要复制任何解除隔离命令。

应用不会上传内容、请求账号、读取原笔记或自动扫描目录。只读取自己的方案文件以及你主动选择的文件。导出文件可能包含你自己输入的内容，分享前请自行检查。

兼容 Apple Silicon 与 Intel 的 Universal 版本；最低 macOS 13（实际架构和最低系统以构建清单为准）。关闭应用不会删除你显式保存的文件。

Quick start

These are standalone Mac utilities. No Xcode, Node, account or network connection is needed. Writing provides a mouse/trackpad canvas, held lines/shapes, waves, fill, fading laser trails, revealable tapes and typed text cards. Export JSON before quitting; Open JSON restores your drawing. It does not perform handwriting recognition on Mac.

Preferences edits its own configuration plans. It does not change macOS or the original life'winner app and does not run the AI, playback, translation or Pencil actions shown as configuration choices. Save stores this tool’s plan in ~/Library/Application Support/InkSpace Preferences/settings.json. Import/Export share validated JSON plans. Invalid imports preserve the current plan.

Both apps use local ad-hoc signing and are not Apple-notarized. macOS may require you to review and allow the app in Privacy & Security after an internet download. Follow Apple’s instructions; do not disable security protections. No automatic uploads or original-note access occur. Check your own exported content before sharing.
