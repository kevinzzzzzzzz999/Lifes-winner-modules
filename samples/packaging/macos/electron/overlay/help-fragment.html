使用帮助 / Getting started

life'winner · 三步开始使用

希望每一个使用我开源功能的人，都是各自的 life'winner。

  1. 点击「打开文档」选择一个文件，或点击「打开工作区」选择一个文件夹。
  2. 从左侧文件列表点击文档；文本会在右侧只读显示，原文件不会被改动。
  3. 用顶部标签切换文档，或按 ⌘K 快速查找已打开的标签。⌘O 打开文档，⇧⌘O 打开新工作区，⌘N 新建窗口。

此版本支持最多 512 KiB 的 UTF-8 文本、Markdown、代码和 Notebook 源文件只读预览。当前支持文本预览；PDF、Office、图片、视频等类型请用适合的软件打开。窗口之间单独授权；选一个文件不会授权相邻文件。

无需安装 Node.js 或 Xcode。没有账户、云端服务、统计上报或自动更新。关闭应用后不保留工作区历史。使用自己选择的文件夹即可；本应用不会自动读取其他软件的数据。

Get started

Choose a document or workspace, then select a file from the list. UTF-8 text previews are read-only and limited to 512 KiB. Use tabs or ⌘K to switch documents. Open PDF, Office, images and video in a suitable application. No Node.js or Xcode installation is required.

This open-source build is ad hoc signed, without Developer ID or notarization. macOS may ask for approval or block first launch. Check the release source and SHA-256 before using the macOS Privacy & Security “Open Anyway” flow if it is offered. No system protection is disabled.
