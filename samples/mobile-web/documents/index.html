    使用帮助与保存说明
    
      
    从选择文件开始
    
      
    “打开文本文件”使用系统的文件选择器。只读取你明确选择的文件；不扫描文件夹、不上传内容。PDF、Office、图片和未知类型不在当前支持范围内，请用适合的软件打开。
    
      
    预览、编辑、保存
    
      
    打开后默认只读。点击“编辑副本”可修改文字或名称。点击“保存到本机”才会保留草稿；未保存的编辑只在当前页面，离开或关闭后可能丢失。切换标签不会丢失当前副本。
    
      
    草稿仅保存在此设备当前浏览器或主屏幕应用中，不会自动同步或备份。清理浏览器数据、系统回收存储或删除应用，可能删除本机草稿。重要内容请导出到“文件”。无痕浏览可能不支持保存。
    
      
    导出到“文件”
    
      
    “导出 .txt”生成下载文件。“分享 / 存到文件”会优先打开系统分享菜单，你可以选择“存储到文件”；不支持文件分享的浏览器会改为下载。保存位置由你选择，若选择 iCloud 等位置，同步由系统或所选服务处理。
    
      
    添加到主屏幕
    
      
    iPhone、iPad 可在 Safari 分享菜单中选择“添加到主屏幕”。首次打开需加载应用；之后离线是否可用以页面显示的离线准备状态为准。本应用不需要 Node.js 或 Xcode。
    
      
    HTML、Markdown 和代码只显示为文字，不执行脚本。这是轻量文本工作台，不是 PDF、Office 或高级代码编辑器。
